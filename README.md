# TP Web N°2 — Générateur de Mots de Passe

**Réalisé par :** AIT HAMMA Rofaida

---

##  Challenges réalisés

###  Challenge A (UI) — Slider de longueur
- Remplacement du champ numérique par un `<input type="range">`
- La valeur choisie s’affiche dynamiquement à côté du label

###  Challenge B (Algo) — Indicateur de force
Barre de progression colorée selon la longueur du mot de passe :
-  **Rouge** : longueur < 8 → *Faible*
-  **Orange** : longueur < 12 → *Moyen*
-  **Vert** : longueur ≥ 12 → *Fort*

###  Challenge C (UX) — Bouton **« Copié ! »**
- Après clic sur **Copier**, le bouton affiche **« Copié ! »** pendant 2 secondes
- Puis revient automatiquement à son état normal
